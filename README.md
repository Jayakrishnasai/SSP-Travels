# SSP Travels

This is the SSP Travels Premium Luxury Bus Travel Experience website, built with [Next.js](https://nextjs.org/).

## Features
- Cinematic scrollytelling experience
- Premium UI with Framer Motion animations
- Smooth scrolling with Lenis
- High-performance bus visuals

## Getting Started

First, run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) (or the port specified in the terminal) with your browser to see the result.
